# Loading Progress Design

## 목표

Clock의 모든 명시적 로딩 상태를 단순 문구나 제각각인 회전 아이콘 대신 하나의 진행 표시 언어로 통일한다. 실제 작업 단위를 셀 수 있는 인프라 대시보드는 완료한 데이터 소스 수를 퍼센트로 보여주고, 전체 크기를 알 수 없는 네트워크 요청과 동적 모듈 로딩은 거짓 퍼센트를 만들지 않는 비확정형 애니메이션으로 표시한다.

## 시각 방향

기존 Split 디자인의 차분한 청회색과 JetBrains Mono를 유지한다. 로딩 표시는 장식적인 원형 스피너가 아니라 작업 궤적을 뜻하는 얇은 수평 레일로 구성한다.

- 트랙: 낮은 대비의 1px 경계와 어두운 면으로 배경을 만든다.
- 진행 중: 실제 퍼센트가 있으면 왼쪽부터 정확히 채운다.
- 비확정형: 28% 폭의 밝은 구간이 레일 안에서만 이동한다.
- 레이블: 사용자가 기다리는 대상과 현재 단계를 완성된 문장으로 표시한다.
- 수치: 실제 진행률이 있을 때만 `0–100%`를 표시한다. 알 수 없는 경우에는 `진행 중`을 표시한다.
- 모서리: 외곽 10px, 레일 3px로 기존 도구 디자인과 맞춘다.
- 움직임: 1.35초 cubic-bezier 이동을 사용하고 `prefers-reduced-motion`에서는 정지한 중앙 구간으로 바꾼다.

## 컴포넌트 계약

`LoadingProgress`는 다음 속성을 받는다.

- `label`: 필수 로딩 대상 문구
- `detail`: 선택적인 현재 단계 문구
- `value`: 실제 완료량. 없으면 비확정형이다.
- `max`: 전체량, 기본값 100
- `compact`: 버튼 주변이나 작은 패널용 밀도
- `className`: 소비 화면의 배치 조정용 클래스

결정형은 `role="progressbar"`, `aria-valuemin`, `aria-valuemax`, `aria-valuenow`를 제공한다. 비확정형은 `aria-valuetext="진행 중"`을 제공한다. 전체 래퍼는 `role="status"`, `aria-live="polite"`를 사용한다.

## 진행률 데이터

인프라 새로고침은 Cluster, Tailscale, NAS의 세 요청을 하나의 배치로 간주한다. 시작 시 `0/3`, 각 요청 완료 또는 실패 시 `1/3`, `2/3`, `3/3`으로 계산한다. 실패한 요청도 해당 네트워크 작업 자체는 끝났으므로 완료 수에 포함하고 오류는 기존 오류 영역에서 별도로 표시한다. 빠른 완료에서도 100% 상태가 인지되도록 짧게 유지한 뒤 진행 표시를 닫는다.

나머지 API는 응답 전체 크기나 총 단계를 제공하지 않으므로 비확정형을 사용한다. 다운로드 바이트 수나 서버 처리 단계가 없는 요청에 시간 기반 가짜 퍼센트를 적용하지 않는다. Speed Test처럼 이미 실제 진행률이 있는 기능은 기존 결정형 진행률을 유지한다.

## 적용 범위

- 앱·대시보드·도구의 Suspense fallback
- 서비스와 즐겨찾기
- Classic Quick Links
- 인프라 Cluster/Tailscale/NAS 배치와 각 탭
- NAS, Google Drive, OneDrive 파일 목록과 업로드 대기
- Repo Catalog, Fortune, Weather, Exchange Rate, Today in History, Todo
- IP/DNS 조회, Arch Icon Search, Calendar, Chat 응답

## 오류와 완료

로딩 표시와 오류 표시는 동시에 남지 않는다. 요청이 실패하면 진행 표시를 제거하고 기존 오류 메시지를 보여준다. 기존 데이터가 있는 상태에서 새로고침하면 데이터는 유지하고 상단의 얇은 진행 표시만 추가하여 화면이 비어 보이지 않게 한다.

## 검증 기준

- 결정형 값은 0–100 범위로 제한된다.
- 값이 없을 때 퍼센트 숫자를 표시하지 않는다.
- 인프라는 세 요청 완료 수에 따라 0, 33, 67, 100%를 표시한다.
- 모든 기존 단순 `Loading...`, `로딩 중` 전용 화면은 공통 진행 표시를 사용한다.
- 모바일에서 가로 넘침이 생기지 않는다.
- 다크·라이트에서 레이블과 트랙 대비가 유지된다.
- 축소 모션 환경에서 이동 애니메이션을 제거한다.
